Hangman Word Guessing Game

A console-based Hangman game built using Python 3. The player guesses a hidden word one letter at a time while trying to avoid six incorrect guesses.

Features

- Random word selection from a text file
- Six incorrect guesses allowed
- ASCII Hangman graphics
- Tracks previously guessed letters
- Prevents duplicate guesses from reducing attempts
- Validates user input
- Win and loss detection
- Option to play again

Technologies Used

- Python 3
- Python standard library ("random")

How to Run

1. Install Python 3.
2. Clone or download this repository.
3. Open a terminal in the project folder.
4. Run:

python Hangman.py

If needed, use "python3 Hangman.py" instead.

How to Play

1. Run the game.
2. Guess one letter at a time.
3. Correct guesses reveal letters in the word.
4. Incorrect guesses use up one of your six attempts.
5. Guess the complete word to win!

Learning Objectives

This project demonstrates Python functions, loops, conditionals, strings, sets, file handling, random selection, and input validation.
