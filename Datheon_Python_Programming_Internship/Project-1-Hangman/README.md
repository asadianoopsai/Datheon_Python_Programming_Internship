Project 1: Hangman Word Guessing Game

Project Overview

The Hangman Word Guessing Game is a console-based Python application in which players attempt to guess a hidden word one letter at a time. The player has a limited number of incorrect guesses to identify the word before the game ends.

This project was developed as part of the Datheon Python Programming Internship.

 Objectives

- Practice Python programming fundamentals.
- Use strings, lists, sets, loops, and conditional statements.
- Implement random word selection.
- Handle user input and validate guesses.
- Track incorrect guesses and remaining attempts.

 Technologies Used

- Python 3
- "random" module
- File handling
- VS Code

 Features

- Random word selection from an external word list.
- Six incorrect guesses allowed.
- ASCII Hangman artwork that changes with incorrect guesses.
- Tracking of previously guessed letters.
- No penalty for repeated guesses.
- Win and loss messages.
- Console-based interactive gameplay.

 How to Run

Prerequisites

Install Python 3 on your computer.

Steps

1. Download or clone this project.
2. Ensure "hangman.py" and "words.txt" are in the same folder.
3. Open a terminal in the project folder.
4. Run the following command:

python hangman.py

If your system uses "python3" to run Python, use:

python3 hangman.py

 How to Play

1. Run the program.
2. Read the instructions displayed in the terminal.
3. Enter one letter at a time to guess the hidden word.
4. Avoid incorrect guesses because you have a maximum of six incorrect attempts.
5. Previously guessed letters should not count as additional incorrect guesses.
6. Guess the entire word before your attempts run out to win.
